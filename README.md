# Blinkit Sales Dashboard Analysis 📊
# Project Overview

This project presents a Blinkit Sales Analysis Dashboard built to analyze sales performance, product categories, outlet performance, and customer preferences.

The dashboard provides insights into total sales, item ratings, outlet establishments, item categories, and product fat content distribution.

The main objective of this project is to:

Analyze sales trends across different product categories

Identify top-performing outlets and products

Understand customer preferences based on item fat content

Track outlet establishment trends over time


# Key Metrics

Total Sales: 1.20M

Number of Items: 9K

Average Item Rating: 3.92

Average Years of Operations: 10.06

# Dashboard Features
1. Filter Panel

The dashboard includes filters that allow users to dynamically analyze the data.

Filters available:

Item Type

Outlet Type

Item Fat Content

Outlet Location Type

These filters help users explore sales performance from different perspectives.

2. Item Type Analysis

Sales distribution is analyzed across different product categories.

Top performing categories include:

Fruits & Vegetables

Snack Foods

Household

Frozen Foods

Insight:
Fruits and Vegetables contribute the highest share to overall sales.

3. Fat Content Analysis

The dashboard compares Low Fat vs Regular Fat products.

Low Fat Products: ~64.6% of total sales

Regular Fat Products: ~35.4% of total sales

Insight:
Customers tend to prefer low-fat products, indicating a shift toward healthier food choices.

4. Outlet Location Performance

Sales are analyzed based on outlet location tiers.

Key observations:

Tier 3 outlets generate the highest sales

Tier 1 and Tier 2 outlets contribute less comparatively

This suggests strong demand in developing areas.

5. Outlet Establishment Trend

The dashboard tracks sales performance across outlet establishment years.

Key observation:

Sales peaked in 2018 (~205K) indicating strong outlet performance during that period.

6. Sales vs Target

A gauge chart compares total sales with the target.

Total Sales Achieved: 1.20M

Sales Target: 2M

This shows that about 60% of the target has been achieved.

# Insights Derived
1. Top Selling Category

Fruits and Vegetables contribute the most to overall sales.

2. Fat Content Impact

Low-fat products generate more sales than regular-fat products.

3. Best Performing Outlets

Tier 3 outlets outperform Tier 1 and Tier 2 outlets.

4. Sales Growth Trend

Sales peaked in 2018 with around 204K.

5. Underperforming Products

There are no items with high visibility but low sales.

This dashboard helps businesses:

Identify high-performing product categories
